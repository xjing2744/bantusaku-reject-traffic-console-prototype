# 拒量引流控台原型

中文静态交互原型，支持产品、上架排序、商户与账户管理。直接打开 `index.html` 即可使用，无需安装依赖。

当前版本：2026-11-04。

- 产品区分贷款产品与信用报告产品，支持按类型查询及复制。
- 产品编辑采用“编辑内容 → 确认变更 → 确认保存”，保留备注、附件和操作记录。
- 安卓和 iOS 分别配置申请中首页、借款已提交页、拒绝锁定页，支持同端跨页面覆盖配置。
- 所有数据均为演示数据，保存在本浏览器中；不连接业务接口，不执行真实资金交易、邮件发送或定时任务。

完整依据、历史调整及验证边界见[说明](说明.md)。说明中后续同日调整覆盖前文被替代的流程；本仓库代码代表当前原型。`产品管理预览.jpg` 为早期预览图，不代表所有最新界面。

本原型用于讨论与评审；原型可配置的字段不自动构成正式业务规则。EasySkor 人群、计费、页面展示与故障控制应以经确认的 PRD 为准。


## 信用报告接入关联原型

2026-11-04 已按本次确认补充[控台产品列表版](credit-preview/index.html)：申请中首页信用报告固定在顶部卡片右下角；其他两页单信用报告沿用原样式，多产品按配置混排。控台底部支持导出产品展示配置，并在前端原型验收工具中导入；该桥接仅用于评审，不是真实业务接口。


## 2026-11-04 申请中首页信用报告展示变更

申请中首页按安卓、iOS分别配置，每端最多上架一个信用报告类型产品；该产品不参与贷款列表混排，不受排序值影响，固定展示于顶部卡片右下角。贷款产品仍按排序展示。控台上架、启用关联上架及跨页覆盖均校验数量；导入无效配置时拒绝读取。借款已提交页和拒绝锁定页保留现有单报告／多产品展示规则。


## 2026-11-05 信用报告图片加载失败

App图片加载失败时隐藏对应报告，其他产品正常展示，剩余列表沿用既定样式／空态。验收工具新增“模拟首个信用报告图片加载失败”；真实列表图片error也执行隐藏。失败记录仅在当前原型场景内生效，切换页面／场景或恢复默认后可重试，不改变控台上架状态。链接异常策略仍待确认。

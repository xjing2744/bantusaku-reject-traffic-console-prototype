# 信用报告接入：控台产品列表版

依据 2026-11-04 用户确认调整，保留三个页面和原有灰模视觉。

## 使用

直接打开 `index.html`。左侧选择平台、页面和产品配置：仅一个信用报告、混排、多个信用报告、仅贷款、空列表。

也可以在上级控台的“原型演示设置与依据”导出产品展示配置，再在本页验收工具中导入。导入只包含产品展示字段与三个页面的上架、排序信息，不包含账户资金、交易或操作记录。这是两个静态原型的演示桥接，不是正式接口设计。

## 当前确认规则

- 三个页面读取控台配置的产品列表，按配置曝光条件筛选；取消固定30天分流、拒量优先与五星门槛。
- 按多账户最短实际剩余锁定时间比较各产品曝光条件。最终可展示列表只有一个信用报告时沿用本页原样式；多个产品使用原贷款列表，信用报告项只展示配置图片，点击读取该产品配置链接。
- 位置曝光、点击复用原拒量引流口径，本页只生成本地演示记录，不实际发送埋点。
- 故障只过滤信用报告，贷款产品继续展示；修复后需人工确认恢复，已打开页面不被强退。
- BTSK不提供资料接口，用户在服务方自行填写。H5内容仅为承接占位。

## 模拟约定及边界

- 示例贷款曝光条件≥15天、报告≤60天，仅用于演示重叠；不是默认业务阈值。
- 本页在浏览器模拟配置筛选。正式App读取服务端返回产品列表，不要求前端自行判定用户资格。
- 正常打开只显示服务方承接占位，所选链接展示在手机外侧说明区。不会访问外部服务或产生资金交易。
- 共用故障在本版演示中作用于信用报告类型；多合作方故障隔离仍需另行明确。
- 导入配置及演示条件刷新后保留；页面/平台/场景切换退出承接页，H5返回恢复当前入口滚动位置。恢复本页默认保留导入文件、当前页面及平台，恢复混排示例并清除该页故障。
- 无可展示产品时，提交成功沿用原评价页／成功弹层，可在验收工具切换原分支；具体原流程判断不在本原型重新设计。图片尺寸、缺图、链接异常时的正式降级等，列入对比报告待确认。
- 原型的旧“数据授权取BTSK资料”、凭证失效及必要认证开关已移除。
